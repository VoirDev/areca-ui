# Foundation for agents

`dev.voir.areca:foundation` is Areca's theme — tokens and `ArecaThemeProvider` — and the
Compose Multiplatform components built on it: buttons, text, fields, selection controls, lists and
settings, collections and tables, layout, navigation and bars, overlays, feedback and status.

```kotlin
implementation("dev.voir.areca:foundation:<version>")
```

Agents load the `areca:areca-ui-v1` skill or read
[skills/areca-ui-v1/SKILL.md](../../skills/areca-ui-v1/SKILL.md): its rules, component choice,
theme, signatures and recipes are the agent guide to this module, and the only one to keep current.

For people: [README.md](README.md) is the module guide and
[docs/components.md](../../docs/components.md) the catalogue of every component.
